Seventies Sound is a three-page website introducing 1970s music to people aged 17-23. It is designed as a friendly starting point for visitors who are either new to the decade or already know a song and want to discover more.

## Project brief

Create a mobile-friendly website that:

- introduces music from 1970 to 1979
- helps visitors browse seven artists across different genres
- provides genre shortcuts and search for artists and songs
- includes official listening links and a short introductory video
- allows visitors to suggest an artist, song or topic
- uses accessible labels, alternative text, captions and keyboard controls
- works consistently on desktop and phone-sized screens

## Pages

- **Home** (`website-design/website/index.html`): introduction, genre cards, a short timeline, and an introductory video with captions and a written version.
- **Explore** (`website-design/website/explore.html`): artist cards, genre filters, search, extra facts, larger-photo controls, and official listening links.
- **Request** (`website-design/website/request.html`): a short suggestion form, privacy information, credits, and accessibility information.

## Featured music

The site introduces these artists and styles:

- ABBA - pop
- David Bowie - glam rock
- Donna Summer - disco
- Fleetwood Mac - rock
- The Clash - punk
- Bob Marley and the Wailers - reggae
- Earth, Wind and Fire - funk and soul

## Technology

The project is built with:

- HTML
- CSS
- vanilla JavaScript
- locally stored images, icons, video captions and written content
- official YouTube links for song videos

## Accessibility and privacy

The site includes a skip link, visible keyboard focus, labelled form controls, alternative text for images, captions for the introductory video, a written video version, keyboard-friendly menus, and an image popup that can be closed with Escape.

The request form does not save submissions. It opens the visitor's email application after the required fields are completed. Visitors are asked not to include private information.

## Running locally

The site is static and can be opened from `website-design/website/index.html` or served from the project directory with any local web server. A local server is recommended so that media and browser interactions behave as expected.
